## 🚀 Projets

### 🏢 OPTIZARH – Gestion RH pour le Secteur Public

Plateforme web intelligente pour automatiser la gestion des RH dans les institutions publiques marocaines.

- **Stack :** Laravel, React, Tailwind CSS, SQLite
- **Fonctionnalités :** Calcul des salaires, IR, RCAR, congés, avancements, états réglementaires
- **Lien :** [OPTIZARH](https://github.com/mohamedBouray/OPTIZARH)

### 📦 Stock Manager – Gestion des Stocks ISTAHT Tanger

Solution sur mesure pour la gestion des approvisionnements et de l'inventaire.

- **Stack :** Laravel, React, Tailwind CSS, SQLite
- **Fonctionnalités :** Codes-barres, inventaire permanent, alertes, rapports PDF
- **Lien :** [Stock Manager](https://github.com/mohamedBouray/stock-manager)
